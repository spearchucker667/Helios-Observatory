# Legal and Attribution Notes

## Helios asset pack

The SVG marks and layouts in this package are original artwork created for Helios Observatory. They deliberately avoid reproducing NASA's official "meatball" insignia, seal, or exact worm logotype. Use "NASA-inspired" only as an internal design descriptor; public copy should describe the style as **space-agency / mission-control inspired** unless an authorized NASA mark is separately approved for use.

## Hatsune Miku

Hatsune Miku is a third-party character/IP associated with Crypton Future Media. The animated GIFs in this package transform the user-supplied Miku spritesheet. No license file was present in the supplied archive. Verify publication rights before committing those GIFs to a public repository or shipping them in a product.

If rights are uncertain, ship the original SVG system only: it is Miku-inspired through palette, twin-tail/comet geometry, and futuristic-idol cues without embedding the source sprite artwork.
